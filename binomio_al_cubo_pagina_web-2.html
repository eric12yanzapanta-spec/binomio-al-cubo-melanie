Binomio al Cubo

Aprende a desarrollar expresiones de la forma (a ± b)³ utilizando una fórmula sencilla, ejemplos paso a paso y ejercicios interactivos.

⏱ 15 min 📚 Nivel: Básico–Intermedio ✏️ Álgebra

Comenzar lección

1. Fundamentación: ¿qué necesitamos saber?

¿Qué es un binomio?

Un binomio es una expresión algebraica formada por dos términos.

a + b

¿Qué significa elevar al cubo?

Significa multiplicar la expresión tres veces por sí misma.

(a + b)³ = (a + b)(a + b)(a + b)

Algoritmo básico

  1. Identifica los valores de a y b.
  2. Observa si el binomio es una suma o una resta.
  3. Aplica la fórmula correspondiente.
  4. Reduce y ordena los términos semejantes.
Ejemplo flash:
(x + 2)³ = x³ + 6x² + 12x + 8

2. Marco teórico

Binomio al cubo de una suma

(a + b)³ = a³ + 3a²b + 3ab² + b³

Binomio al cubo de una resta

(a − b)³ = a³ − 3a²b + 3ab² − b³

Regla para recordar

TérminoForma
Primeroa³
Segundo3a²b
Tercero3ab²
Cuartob³

Ejemplo de tu cuaderno

(x − 2)³

= x³ − 3(x)²(2) + 3(x)(2)² − 2³

= x³ − 6x² + 12x − 8

Resultado: x³ − 6x² + 12x − 8

Glosario rápido

a: primer término del binomio.
b: segundo término del binomio.
³: indica que la expresión se eleva al cubo.
3: coeficiente que aparece en los términos centrales.

4. Banco de ejercicios resueltos

(x + 2)³ = x³ + 3x²(2) + 3x(2²) + 2³

(x + 2)³ = x³ + 6x² + 12x + 8

Respuesta: x³ + 6x² + 12x + 8

(x − 3)³ = x³ − 3x²(3) + 3x(3²) − 3³

(x − 3)³ = x³ − 9x² + 27x − 27

Respuesta: x³ − 9x² + 27x − 27

(2x + 3)³ = (2x)³ + 3(2x)²(3) + 3(2x)(3²) + 3³

= 8x³ + 36x² + 54x + 27

Respuesta: 8x³ + 36x² + 54x + 27

(3a − 2b)³ = (3a)³ − 3(3a)²(2b) + 3(3a)(2b)² − (2b)³

= 27a³ − 54a²b + 36ab² − 8b³

Respuesta: 27a³ − 54a²b + 36ab² − 8b³

5. Práctica autónoma y evaluación

⚠ Errores comunes
  • Olvidar los coeficientes 3 de los términos centrales.
  • Confundir el signo de los términos cuando el binomio es una resta.
  • Escribir b² o b³ incorrectamente.
  • No elevar correctamente cada término a la potencia indicada.

Ejercicios para practicar

2. (x − 5)³
3. (2x + 1)³
4. (3a − b)³
